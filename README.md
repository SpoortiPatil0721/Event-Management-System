Project Overview

**CampusBuzz** is a web-based College Event Management System designed to simplify the process of organizing, managing, and participating in college events.

The system provides a centralized platform where students can explore upcoming events, register for events, provide feedback, and manage their participation. Administrators can create, update, and manage events, monitor registrations, track attendance, and manage event-related activities.

The project aims to replace manual event management processes with a digital and user-friendly system.

---

## Features

### Student Module

- User Registration and Login
- Secure Authentication
- View Upcoming College Events
- Register for Events
- View Event Details
- Student Dashboard
- Attendance Tracking
- Submit Feedback and Ratings
- Forgot Password and Password Reset
- Email/OTP Verification

---

### Admin Module

- Secure Admin Login
- Admin Dashboard
- Add New Events
- Manage Existing Events
- Delete Events
- View Event Registrations
- Track and Update Attendance
- Manage Student Participation
- Monitor Event Feedback

---

### Event Management Features

- Create and Manage College Events
- Display Event Details
- Event Registration System
- Attendance Management
- Feedback Collection
- Certificate Management
- Email Notifications
- Password Recovery using OTP
